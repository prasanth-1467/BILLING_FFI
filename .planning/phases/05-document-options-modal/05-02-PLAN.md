# Plan 05-02: Integrate Modal into Invoices and Quotations & Clean Up Toolbars

## Objective
Wire `DocumentOptionsModal` into both the Invoices and Quotations modules. Remove always-visible toolbar toggles, intercept row Download/Print clicks to display the modal with document-specific context, and forward user-confirmed settings to the existing backend PDF generator.

## Tasks

1. **Clean Up `Invoices.jsx` Toolbar**:
   - Remove the permanent toolbar checkboxes: `Include Signature`, `Include Seal`, and `Include Shipping`.
   - Preserve search input, theme selector, copy badge selector, and "New Invoice" primary button.

2. **Clean Up `Quotations.jsx` Toolbar**:
   - Remove the permanent toolbar checkboxes: `Include Shipping Address`, `Include Signature on PDFs`, and `Include Seal on PDFs`.
   - Preserve search, quotation/proforma switcher tabs, and "New Quotation" button.

3. **Contextual Modal State Management in `Invoices.jsx`**:
   - Introduce state:
     ```javascript
     const [docOptionsModal, setDocOptionsModal] = useState({
       isOpen: false,
       actionType: 'download', // 'download' | 'print'
       document: null // current invoice object
     });
     ```
   - Intercept table row actions:
     - Download click (`onClick={() => openDocOptions(invoice, 'download')}`)
     - Print click (`onClick={() => openDocOptions(invoice, 'print')}`)
   - Handle confirmation:
     - Execute `handleDownload` or `handlePrint` passing `{ includeSignature: opts.includeSignatureAndSeal, includeSeal: opts.includeSignatureAndSeal, includeShippingAddress: opts.includeShippingAddress }`.
     - Close modal upon completion.
     - Ensure independent state: opening or canceling for one invoice does not persist across or mutate other rows.

4. **Contextual Modal State Management in `Quotations.jsx`**:
   - Replicate the exact same modal integration:
     - Intercept Download and Print row actions.
     - Pass confirmed options to quotation PDF generator API.
     - Clean, predictable behavior on quote actions.

## Acceptance Criteria
- [ ] Permanent signature, seal, and shipping checkboxes removed from both `Invoices.jsx` and `Quotations.jsx` toolbars.
- [ ] Clicking Download on an invoice row triggers `DocumentOptionsModal` with "Download PDF" primary button.
- [ ] Clicking Print on an invoice row triggers `DocumentOptionsModal` with "Print Document" primary button.
- [ ] Clicking Download/Print on a quotation row triggers `DocumentOptionsModal` for that specific quotation.
- [ ] Canceling modal leaves document unaffected and does not trigger PDF generation.
- [ ] Confirmed options correctly reach the existing server-side PDF endpoints.
