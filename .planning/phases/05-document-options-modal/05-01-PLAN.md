# Plan 05-01: Reusable DocumentOptionsModal Component Architecture

## Objective
Design and implement a clean, accessible, and theme-aware `DocumentOptionsModal` component that presents document export options contextually upon clicking Download or Print, eliminating permanent toolbar toggle clutter.

## Context
Currently, `Invoices.jsx` and `Quotations.jsx` display always-visible checkboxes for "Include Signature", "Include Seal", and "Include Shipping" directly in their page toolbars. Moving these into a contextual modal shown just before PDF generation creates a streamlined, modern user experience.

## Component Specifications (`DocumentOptionsModal.jsx`)

1. **Header**:
   - Title: `Document Options`
   - Subtitle: `Customize how your document appears before downloading or printing.`
   - Close (X) button in top-right.

2. **Option Cards (Checkbox Cards)**:
   - **Card 1: Include Signature & Seal**
     - Label: `Include Signature & Seal`
     - Description: `Include the authorized signature and company seal in the document.`
     - State mapping: Controls both `includeSignature` and `includeSeal`.
   - **Card 2: Include Shipping Details**
     - Label: `Include Shipping Details`
     - Description: `Include the shipping address and delivery information.`
     - State mapping: Controls `includeShippingAddress`.
   - Cards must have clear visual states: distinct border and background highlight when active/checked, smooth hover feedback, and clickable full-card hit areas.

3. **Contextual Action Buttons**:
   - **Download flow (`actionType === 'download'`)**:
     - Primary button: `Download PDF` (with `Download` icon or loading spinner)
     - Secondary button: `Cancel`
   - **Print flow (`actionType === 'print'`)**:
     - Primary button: `Print Document` (with `Printer` icon or loading spinner)
     - Secondary button: `Cancel`

4. **Accessibility & UX**:
   - Keyboard accessible: `Escape` key closes modal, `Enter` key confirms action, `Tab` navigates between cards/buttons.
   - Backdrop click dismisses modal.
   - Clean dark/light theme styling using existing theme tokens and CSS variables (`--bg-main`, `--card-bg`, `--border-main`, `--primary-accent`).
   - Smooth entrance animation (`animate-slideDown` / `animate-scaleIn`).

## Acceptance Criteria
- [ ] `DocumentOptionsModal.jsx` component created in `billing-frontend/src/components/common/`.
- [ ] Renders correctly with both `download` and `print` action variants.
- [ ] Allows independent toggling of Signature & Seal and Shipping Details.
- [ ] Clean dark and light mode visual contrast.
- [ ] Production build passes without TypeScript/linter errors.
