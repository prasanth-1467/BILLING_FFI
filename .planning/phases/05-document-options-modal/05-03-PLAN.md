# Plan 05-03: Cross-Document Verification, Theme Validation & Build Stability

## Objective
Verify the end-to-end functionality of the contextual `DocumentOptionsModal` across various permutations, ensuring flawless visual contrast in both dark and light modes, accurate PDF generation, isolation across multiple rows, and production build readiness.

## Verification Checklist

1. **Download Variations**:
   - [ ] Download with both Signature & Seal AND Shipping Details enabled -> Generates PDF with signatures, seal image, and Ship To card.
   - [ ] Download with Signature & Seal disabled -> Generates PDF without signature lines or seal image.
   - [ ] Download with Shipping Details disabled -> Generates PDF with only Bill To (omitting Ship To).
   - [ ] Download with both options disabled -> Minimal clean document.

2. **Print Variations**:
   - [ ] Print with Signature & Seal + Shipping Details enabled -> Opens print buffer with both.
   - [ ] Print with custom selections -> Matches selected configuration.

3. **Multi-Document & State Isolation**:
   - [ ] Opening modal on Invoice A, changing toggles, and closing -> Opening Invoice B shows clean default selections without cross-contamination.
   - [ ] Switching between Invoices page and Quotations page -> Options are contextually bound to the selected document.
   - [ ] Canceling modal -> No network request, no download, no print trigger.

4. **UI & Accessibility**:
   - [ ] Dark Mode: Dark obsidian surfaces (`#111726` / `#172033`), clear borders (`#1F2B45`), vibrant orange accents (`#FF7A18`).
   - [ ] Light Mode: Clean white surfaces, soft border contrast, no invisible or low-contrast text.
   - [ ] Responsive Viewports: Verified on mobile and laptop screen widths.
   - [ ] Keyboard navigation: `Escape` dismisses, `Enter` executes action, `Space` toggles checkbox.

5. **Build & Regression Integrity**:
   - [ ] `npm run build` succeeds in `billing-frontend` without errors or bundle warnings.
   - [ ] Existing GST calculations, numbering, and database records remain 100% untouched.
