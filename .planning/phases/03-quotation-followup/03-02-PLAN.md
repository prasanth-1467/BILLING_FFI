# Plan 03-02: Quotation Follow-up Workflow UI, Schedule Modal & WhatsApp Actions

## Objective
Enhance `Quotations.jsx` with follow-up status badges, overdue indicators, a modal to schedule/edit follow-up dates and notes, and one-click WhatsApp message triggers for seamless quotation follow-ups.

## Context
Once quotations are sent, staff need a clear visual reminder of which quotations need follow-up today, which are overdue, and a fast way to reach the customer via WhatsApp with quote details.

## Tasks
1. **Quotation Table Follow-up Column & Badges**:
   - Render follow-up status:
     - Due Today: pulsing amber badge.
     - Overdue: rose badge showing days late.
     - Scheduled: clean slate/sky date indicator.
     - None: lightweight "Schedule" shortcut button.
2. **Schedule / Edit Follow-up Modal**:
   - Dialog allowing staff to:
     - Select a follow-up date (native date input).
     - Select status (`Pending`, `Contacted`, `Awaiting Approval`, `Negotiation`, `Won`, `Lost`).
     - Enter concise notes (e.g., "Customer asked to verify 2-inch pipe stock").
   - Saves via `PATCH /api/quotations/:id/follow-up` and refreshes table without full reload.
3. **One-Click WhatsApp Follow-up Action**:
   - WhatsApp icon button generating a personalized message:
     `Hello [Customer Name], following up from Fine Flow Irrigation regarding Quotation #[QuoteNumber] for ₹[Amount]. Please let us know if you need any technical adjustments.`
   - Deep links directly to `https://wa.me/91[Phone]`.
4. **Follow-up Quick Filter**:
   - Add filter tabs: `All`, `Follow-up Due / Overdue`, `Draft`, `Sent`, `Approved`, `Converted`.

## Acceptance Criteria
- [ ] Schedule Follow-up modal opens, saves, and updates the table row in real time.
- [ ] WhatsApp button generates pre-formatted quotation inquiry message.
- [ ] Follow-up filter isolates quotations requiring immediate outreach.
