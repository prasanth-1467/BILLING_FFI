# Plan 01-01: Responsive Shell, Mobile Drawer & Glassmorphism Header

## Objective
Modernize the primary application shell (`MainLayout.jsx`) to provide a professional, responsive layout with mobile drawer navigation, streamlined menu grouping, and a high-contrast top bar.

## Context
Currently, `MainLayout.jsx` uses a fixed `w-64` desktop sidebar with no mobile responsive drawer or hamburger toggle. On smaller screens (<1024px), content overflows or becomes squished. Additionally, the navigation menu contains redundant links ("Quotations" and "Create Quotation", "Invoices" and "Create Invoice").

## Tasks
1. **Responsive Shell & Mobile Drawer**:
   - Add responsive state (`isMobileMenuOpen`) and a hamburger button in the sticky top header for viewports `< 1024px`.
   - Render a mobile drawer with slide-in transition and backdrop blur overlay that closes on navigation.
2. **Streamlined Navigation Hierarchy**:
   - Organize sidebar links into clear functional categories:
     - **Core**: Dashboard
     - **Commercial**: Invoices, Quotations, Purchase Orders
     - **Master Data**: Customers, Products
     - **Compliance & Tools**: E-Way Bill Sandbox
     - **Intelligence**: Agent Intelligence
   - Highlight active route with indigo glow pill and subtle indicator.
3. **Glassmorphism Header Polish**:
   - Refine page title, active date badge, and user action buttons (NotificationBell, Profile trigger, Logout).
   - Ensure sticky header maintains `z-30` above page content with smooth backdrop blur.

## Acceptance Criteria
- [ ] Mobile navigation toggle opens and closes drawer smoothly without layout shift.
- [ ] Clicking any navigation link on mobile closes the drawer and navigates cleanly.
- [ ] Desktop sidebar is fixed, clean, and beautifully styled with clear active route indicators.
- [ ] Zero changes to existing route paths or protected route authorization.
