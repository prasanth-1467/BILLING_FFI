# Plan 02-02: Executive CRM Dashboard, Receivables Aging & Agent Center UI

## Objective
Rebuild `Dashboard.jsx` into an executive command center featuring financial KPI cards, a visual Receivables Aging breakdown, a Quotation Conversion Funnel, and an integrated Autonomous Agent feed with one-click actions.

## Context
The current dashboard lacks quotation visibility, has no aging categorization beyond a single overdue sum, and does not surface the autonomous background agent suggestions from `InsightAgent`, `InvoicerAgent`, and `RestockAgent`.

## Tasks
1. **Executive Financial KPI Ribbon**:
   - Monthly Revenue with trend comparison.
   - Total Outstanding Receivables with aging risk indicator.
   - Active Quotation Pipeline Value with conversion rate.
   - Low Stock Alert count with direct reorder link.
2. **Visual Receivables Aging Breakdown**:
   - Horizontal bucket meter showing Current, 1–30d, 31–60d, 61–90d, and 90+d overdue amounts.
   - Critical Overdue Accounts table: list of top balances with one-click WhatsApp payment reminders and direct payment modal.
3. **Quotation Pipeline Funnel**:
   - Visual stages: Draft → Sent → Approved → Converted with values and conversion percentage.
   - Direct CTA to convert approved quotations or draft new proposals.
4. **Live Autonomous Agent Intelligence Feed**:
   - Embed active notifications generated by background agents (`Daily Revenue Insight`, `Payment Follow-up`, `Low Stock Alert`, `Invoice Suggestion`).
   - One-click resolution (e.g. click "Convert" on Invoice Suggestion, click "WhatsApp" on payment follow-up).

## Acceptance Criteria
- [ ] Dashboard displays accurate aging buckets and quotation funnel.
- [ ] WhatsApp reminder button generates professional payment request messages.
- [ ] Payment modal records payments and triggers real-time dashboard refresh.
- [ ] Dashboard loads with `TableSkeleton` / metric skeletons without layout shift.
