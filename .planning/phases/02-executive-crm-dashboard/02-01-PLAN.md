# Plan 02-01: Receivables Aging Engine & Enhanced CRM Aggregations API

## Objective
Enhance `/api/stats` to compute receivables aging buckets (Current, 1–30 days, 31–60 days, 61–90 days, 90+ days overdue), quotation conversion pipeline stages, and cashflow metrics on the server, avoiding expensive full-table scans on client devices.

## Context
Currently, `statsRoutes.js` only returns simple totals (totalSales, totalInvoices, totalCustomers, lowStockCount, monthlySales). The frontend client-side calculates parts of the invoice balances. As the invoice and quotation volume expands, server-side aggregations guarantee rapid dashboard boot times.

## Tasks
1. **Compute Receivables Aging Buckets (`statsRoutes.js`)**:
   - Query all unpaid invoices (`balance > 0`).
   - Group balances based on difference between `dueDate` (or invoice `date`) and `now`:
     - `current` (due in future or due today)
     - `days1to30` (1 to 30 days overdue)
     - `days31to60` (31 to 60 days overdue)
     - `days61to90` (61 to 90 days overdue)
     - `days90plus` (> 90 days overdue)
2. **Compute Quotation Pipeline Stages (`statsRoutes.js`)**:
   - Aggregate Quotations by status (`Draft`, `Sent`, `Approved`, `Converted`, `Rejected`).
   - Compute total quotation pipeline value and overall conversion percentage.
3. **Include Active Notifications Summary**:
   - Fetch the latest 5 unread high/medium priority agent notifications (`Notification` model) for instant dashboard surfacing.

## Acceptance Criteria
- [ ] `GET /api/stats` returns `aging` buckets with correct financial sums.
- [ ] `GET /api/stats` returns `quotationPipeline` with stage counts and total values.
- [ ] Existing fields (`totalSales`, `totalInvoices`, `totalCustomers`, `lowStockCount`, `monthlySales`, `recentInvoices`) remain 100% backward-compatible.
