# Tech Stack: Fine Flow Irrigation Billing & CRM

## Core Technologies
- **Frontend**: React 18, Vite, Tailwind CSS, Lucide React, Recharts, React Router DOM v6
- **Backend**: Node.js, Express.js 4, Mongoose 8 / MongoDB
- **Authentication**: JWT (`jsonwebtoken`), `bcryptjs`
- **Document Generation**: `pdfkit`
- **Automation / Background Jobs**: `node-cron`
- **Dev & Tooling**: ESLint, PostCSS, Tailwind CLI

## Key Libraries & Responsibilities
- `pdfkit`: High-performance PDF generation for Invoices, Quotes, and Purchase Orders.
- `recharts`: Analytical visualization for cashflow, revenue, and customer distributions.
- `lucide-react`: Standardized icon system across navigation, tables, and metric badges.
- `date-fns`: Date formatting, overdue calculations, and aging difference calculations.

## Rule
Adding a new dependency requires explicit user approval and a one-line rationale recorded here.
