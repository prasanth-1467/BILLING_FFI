# Ralph Loop
Role: iterative execution of small tasks. Reads `PRD.md`, writes `progress.txt`.
Config (record the real values after inspecting): mode, model, max iterations, stable threshold, git integration, branch-per-session.
Rules: one task at a time; run the verify step; stop at the iteration limit and report; no architecture changes; no edits to `.planning/`.
Good tasks: small, with a test or a browser check. Bad tasks: "make it look better", "refactor everything".
